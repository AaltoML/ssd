Paper & discussion ↗

The idea

Learn from fewer positions.
Generate complete images.

Diffusion models can produce images that are locally plausible yet globally inconsistent. SSD applies random masks when computing the regression loss, training on a subset of target entries while retaining the full noisy input.

Our experiments study population-score estimation, memorization, contextual sensitivity, and spatial consistency. A covariance-spectrum analysis motivates the approach; the proposed connection between these effects remains a hypothesis supported by the evidence.

01 / Method

A few lines in the loss.

The pixel-space U-Net implementation independently masks regression-loss entries across positions and channels.

01

Predict as usual

The network receives the complete noisy image and predicts the target velocity or noise.

02

Sample a loss mask

Draw a fresh Bernoulli mask for the unreduced squared error at each training step.

03

Average retained entries

Normalize by the number of unmasked entries, then update the model.

Pixel-space SSD · PyTorch
# Input and prediction stay unchanged
error = (prediction - target).square()
mask = (torch.rand_like(error) >= eta).float()
loss = (error * mask).sum() / mask.sum().clamp(min=1)

η = 0 recovers the dense regression objective.

ImageNet implementation. The released DiT experiments apply masks to already reduced per-image diffusion losses, averaging multiple masks from one forward pass. This experimental variant is preserved and documented in the DiT code.

04 / Reproduction

Start with the code.

Both the U-Net and DiT codebases are available, with portable launchers, experiment settings, evaluation instructions, and the CelebA-50K filename manifest.

Reproduction guide ↗

Datasets and weights are not bundled. Exact preprocessing and subset limits are documented in the repository.

A CelebA-50K run
git clone https://github.com/wenshuaizhao/ssd.git
cd ssd
pip install -r requirements.txt
pip install -e .

python scripts/run_unet.py \
  --dataset celeba_50k_64x64 \
  --data-path /path/to/celeba50k \
  --output-dir outputs/celeba-ssd \
  --mask-prob 0.8

Use a compatible CUDA-enabled PyTorch installation.
